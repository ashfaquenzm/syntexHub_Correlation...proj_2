# Correlation Heatmap & Pairwise Analysis

An interactive data visualization application built using **Streamlit**, **Pandas**, and **Seaborn**.

## 📌 Features
- Generates correlation matrix heatmaps for numerical dataset features
- Visualizes pairwise relationships and distributions
- Built with custom aesthetics and Seaborn styling

## 🛠️ Tech Stack
- **Python**
- **Streamlit** (Web UI)
- **Pandas** (Data manipulation)
- **Seaborn & Matplotlib** (Data visualization)

## 🚀 How to Run Locally

1. Clone this repository:
   git clone https://github.com/ashfaquenzm/syntexHub_Correlation-heatmap-pairwise_p_2.git

2. Install dependencies:
   pip install -r requirements.txt

3. Run the Streamlit app:
   streamlit run app.py
